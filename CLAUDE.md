# lego-creator

Original LEGO SPIKE Prime builds: LDraw models, kit-constrained BOM checks, building instructions and Pybricks programs.

## Layout

- `models/<slug>/` — one build: `model.yaml` (name, kits, status), `model.mpd` (source of truth), `spec.md` (intent, mechanism, open questions), `program/main.py` (Pybricks). `out/` is generated and ignored.
- `templates/` — reusable submodels to copy into a model's `.mpd` as a `0 FILE` (e.g. `lms-esp32v2-mount.mpd`); `test_real_data.py` checks they resolve.
- `inventory/<set>.csv` — kit inventories. Rebrickable sets (`<num>-1.csv`) are generated by `lc import-inventory`; other kits (`lms-esp32v2`, `tank-tracks`) are hand-written. A blank `quantity` means owned but count unknown: `lc validate` skips the shortage check and warns `quantity-unknown`. `inventory/id-map.csv` maps LDraw id → kit part.
- `ldraw/` — official LDraw library, not committed (`uv run lc fetch-ldraw`).
- `custom/parts/` — unofficial parts for non-LEGO hardware (searched after `ldraw/`, cannot shadow official parts). Generated by `scripts/gen_*.py`; regenerate rather than hand-edit. Each has a matching `inventory/<id>.csv` pseudo-kit.
- `.local/owned.yaml` — personal collection (not committed). `kits: {set: qty}` is the default for `lc new`; `model.yaml` `kits` uses the same `{set: qty}` form.
- `design/` — synced copy of the Brick Steps design system tokens (`source.json` records the artifact version). Never hand-edit; change the artifact, then re-sync.
- `docs/adr/` — architecture decisions. `.github/workflows/pages.yml` builds and deploys the site.
- `src/lego_creator/` — `lc` CLI; `site_assets/` holds the site's component CSS, manual.js and service worker. `tests/` — pytest; `test_real_data.py` is skipped until `ldraw/` exists.

## Commands

- `uv run lc new <slug> [--kit 45678-1 --kit 45681-1]`
- `uv run lc validate <slug>` — exit 1 on any error
- `uv run lc bom <slug>`
- `uv run lc instructions <slug> [--no-pdf]` — one manual (HTML + PDF) into `models/<slug>/out/manual/`
- `uv run lc site [--include-drafts] [--no-pdf]` — gallery + manuals into `site/` (what GitHub Pages serves)
- `uv run lc fetch-ldraw`, `uv run lc import-inventory 45678-1 45681-1`
- `uv run lc release-check vX.Y.Z` — tag, pyproject and CHANGELOG agree; prints release notes
- `uv run pytest`

## Rules

- Load the `ldraw-spike` skill before writing or reviewing any `.mpd` content.
- A model change is done only when `lc validate` reports 0 errors.
- Hub ports are declared only in the `.mpd` (`0 !LC PORT`); do not duplicate them in `model.yaml`.
- `lc validate` checks line syntax, rotation matrices (proper rotation, det +1), color codes against LDConfig, part resolution, aliases, kit inventory and ports. It does not check physical connectivity, collisions, grid alignment or mechanism behaviour; those need human review in a viewer (LeoCAD/LDCad) or on the real build.
- Instruction export needs LeoCAD 25.09, Xvfb and Pango (ADR 0001). The site is kid-facing Korean; only `status: ready` models are published.
- Site look follows the Brick Steps design system, a private claude.ai artifact (link in `CLAUDE.local.md`). Read its README before changing `site_assets/components.css`; every value there must come from a token.
- Add a line under `## [Unreleased]` in `CHANGELOG.md` in the same commit as any user-visible change. Releases follow `docs/releasing.md`: 0.0.z is the beta series and only PATCH is bumped until the maintainer says otherwise.
